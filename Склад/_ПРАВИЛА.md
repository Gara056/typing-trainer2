# Правила папки «Склад»

Корень на железе: **`D:\Склад`**.
В репозитории эта же структура лежит в папке `Склад/` — скопируйте её на D: один раз.

Цель: не помойка. Файлы живут в проекте, внутри проекта — по событию, внутри события — по типу.

## Дерево

```
D:\Склад\
  _ПРАВИЛА.md          ← этот файл, не трогать без нужды
  _каталог.md          ← оглавление, агент обновляет при каждом новом файле
  входящие\            ← сюда кидаете сырьё, ещё не разобранное
  проекты\
    КФХ-Галимова\
      2026-09-15 Привезли\
        исходники\     ← PDF, сканы, фото документов
        таблицы\       ← xlsx, csv
        прочее\        ← всё остальное по этой поставке
    Лила\
  шаблоны\             ← пустые бланки, не рабочие копии
  архив\               ← закрытые проекты целиком, не отдельные файлы
```

## Закон (для человека и для агента)

1. **В корне `D:\Склад` нет файлов**, кроме `_ПРАВИЛА.md` и `_каталог.md`.
2. Новый непонятный файл → только во **`входящие`**. Оттуда его разбирают в проект в тот же день.
3. Сначала **проект**, потом **дата + событие**, потом **тип файла**. Не наоборот: не делать папок «все PDF» и «все Excel» на весь диск.
4. Одна поставка / один счёт / один завоз = **одна папка** `ГГГГ-ММ-ДД Краткое имя`.
5. Имена файлов: `ГГГГ-ММ-ДД_суть.расширение`  
   Пример: `2026-09-15_счет-4553.pdf`
6. Исходник и таблица по нему лежат **в одной** папке события, в разных подпапках (`исходники` / `таблицы`).
7. Не копировать один файл в три места. Нужна ссылка — ярлык Windows, не дубль.
8. Закрыли тему → папка проекта целиком в **`архив\ГГГГ\`**, не россыпью.
9. После любого добавления агент дописывает строку в **`_каталог.md`**.

## Что куда из типичных файлов

| Что пришло | Куда |
|---|---|
| Скан счёта, УПД, накладная | `проекты\…\событие\исходники\` |
| Excel, который собрали из скана | `проекты\…\событие\таблицы\` |
| Фото с телефона «пока неясно» | `входящие\` |
| Пустой бланк сметы | `шаблоны\` |
| Игра «Лила», html, код | `проекты\Лила\` — не смешивать со складом КФХ |

## Как открывать на Windows

В Проводнике: `D:\Склад`. Дальше только `проекты` и нужная дата.
Не складывать рабочее на Рабочий стол и в Загрузки.

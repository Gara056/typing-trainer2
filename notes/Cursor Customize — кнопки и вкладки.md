# Cursor Customize — кнопки и вкладки

> Шпаргалка по странице **Customize** в Cursor (скриншот: вкладка Hooks, 21.08.2026).
> Документация: [Customize](https://cursor.com/docs/customize-cursor) · [RU](https://cursor.com/ru/docs/customize-cursor)

Единое место, где настраивается поведение агента: плагины, навыки, внешние сервисы и правила. Область действия обычно: только вы / этот проект / вся команда.

## Верхняя панель

**Поиск** (`Search Plugins, Skills, MCPs...`) — ищет по каталогу плагины, навыки и MCP-серверы, не уходя со страницы.

**Browse Marketplace** — открывает [Cursor Marketplace](https://cursor.com/marketplace): каталог официальных и командных расширений. Установка обычно в один клик.

**Профиль** — меню аккаунта: аккаунт, команда, биллинг, настройки профиля.

## Вкладки категорий

Это разные типы кастомизации. Их можно ставить по отдельности или пакетом внутри плагина.

| Вкладка | Зачем | Документация |
| --- | --- | --- |
| **Plugins** | Готовые наборы: правила, навыки, сабагенты, команды, MCP и хуки в одном пакете | [plugins](https://cursor.com/docs/plugins) |
| **MCPs** | Подключения к внешним системам (GitHub, Linear, Notion, БД, свои API) | [mcp](https://cursor.com/docs/mcp) |
| **Skills** | Узкие инструкции «как делать эту задачу»; агент подхватывает сам или через `/имя` | [skills](https://cursor.com/docs/skills) |
| **Subagents** | Отдельные помощники со своим контекстом; можно запускать параллельно | [subagents](https://cursor.com/docs/subagents) |
| **Rules** | Постоянные инструкции агенту (стиль, соглашения, ограничения) | [rules](https://cursor.com/docs/rules) |
| **Commands** | Готовые действия по `/` в чате агента | [customize](https://cursor.com/docs/customize-cursor) |
| **Hooks** | Скрипты на события цикла агента (до/после правки, перед шеллом, перед MCP) | [hooks](https://cursor.com/docs/hooks) |

### Plugins

Готовые наборы. Один плагин может сразу принести правила, навыки, сабагентов, команды, MCP и хуки. Удобно, когда нужен целый рабочий стек (например, Linear или Figma), а не ручная сборка.

### MCPs

Подключения к внешним системам по Model Context Protocol. Здесь включают/выключают серверы и добавляют свои (`mcp.json`: проектный `.cursor/mcp.json` или пользовательский `~/.cursor/mcp.json`).

### Skills

Узкие пакеты знаний. Агент подхватывает их сам, когда задача похожа, или вы вызываете через `/имя-скилла`. Это не постоянные правила, а инструкции на случай.

### Subagents

Отдельные помощники, которым основной агент отдаёт куски работы. У каждого своё окно контекста. Есть встроенные вроде Explore, Bash, Browser; свои тоже можно добавить.

### Rules

Постоянные инструкции агенту: стиль кода, соглашения репозитория, что нельзя делать. Они почти всегда в контексте чата, в отличие от скиллов.

### Commands

Готовые действия по `/` в чате агента. Например, `/review` или `/commit` — markdown-шаблон, который сразу запускает нужный сценарий.

### Hooks

Скрипты на события цикла агента: до/после правки файла, перед командой в терминале, перед вызовом MCP. Ими можно форматировать код, блокировать опасные команды, ловить секреты в диффе.

Конфиг: проектный `<project>/.cursor/hooks.json` или пользовательский `~/.cursor/hooks.json`. Приоритет: Enterprise → Team → Project → User.

## Кнопки внутри Hooks

**Open config** — открывает `hooks.json`, где прописываются события и скрипты.

**Documentation** — официальная справка: [cursor.com/docs/hooks](https://cursor.com/docs/hooks) · [RU](https://cursor.com/ru/docs/hooks).

**Clear log** — очищает журнал запусков хуков на этой странице. Серая, если чистить нечего.

**Execution Log** (`No hook executions yet`) — живой лог срабатываний. Пусто значит: за эту сессию ни один хук ещё не отработал (нет настроенных хуков, агент ещё не дошёл до нужного события, или лог уже очищали).

## Кратко

Вкладки слева — *что* настраивать. Marketplace — *откуда ставить*. В Hooks кнопки — *как править конфиг, читать документацию и смотреть, сработали ли скрипты*.

# Open Design — как пользоваться UI после запуска

Статус: daemon работает, в браузере открыт **http://127.0.0.1:7456** («Открытый дизайн»).  
Проект виден: **«Тренажер для печати»** · произвольная форма · Не начато.

## Windows (важно)

Скрипты `.sh` в PowerShell не поднимают daemon. Рабочие команды:

```powershell
cd C:\Users\gboya\typing-trainer2
npm install
npx open-design-ade --no-open --host 127.0.0.1 --port 7456
```

Терминал с `npx open-design-ade` не закрывать.  
Проверка: браузер → http://127.0.0.1:7456

Ветка: `cursor/open-design-agent-c0a3`

## Способ 1 — в браузере Open Design

1. Открыть http://127.0.0.1:7456
2. Клик по карточке **«Тренажер для печати»**
3. Если нужно создать новый:
   - название, например `practice-screen`
   - дизайн-система: `typing-trainer` если есть, иначе нейтральная
   - детализация: **Высокая детализация**
   - **+ Создать**
4. В чат проекта вставить промпт:

```text
Сделай экран практики набора текста:
- крупный бренд Typing Trainer
- одна строка задания
- mono-текст для печати
- WPM и accuracy внизу
- без карточек в hero
- тёплая бумага, акцент teal
```

5. Смотреть preview → править текстом («крупнее текст», «добавь анимацию ошибки»).

Внизу UI: **Локальный CLI · Claude Code** — генерацию ведёт локальный агент. API key/модель — в Settings Open Design при необходимости.

## Способ 2 — из Cursor Agent (MCP зелёный)

Промпт:

```text
Используй Open Design MCP.
Открой проект typing-trainer2 (или «Тренажер для печати»).
Сгенерируй high-fidelity practice screen и сохрани HTML в проект.
Опирайся на DESIGN.md.
```

Результат смотреть снова на http://127.0.0.1:7456

## Успех

- В проекте есть HTML/preview экрана практики
- Можно итерировать текстом
- Можно экспортировать/скачать из UI
